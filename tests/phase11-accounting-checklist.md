# ATLAS Fase 11 — Pruebas contables

1. Venta de contado: Debe Caja / Haber Ventas + IVA; Debe Costo de ventas / Haber Inventario.
2. Venta a crédito: Debe CxC en vez de Caja.
3. Compra de contado: Debe Inventario + IVA crédito fiscal / Haber Caja.
4. Compra a crédito: Haber CxP.
5. Cobro de CxC: Debe Caja / Haber CxC.
6. Pago de CxP: Debe CxP / Haber Caja.
7. Devolución: reversa Ventas + IVA y reversa Costo de ventas/Inventario.
8. Gasto: Debe Gasto / Haber Caja.
9. Balance de comprobación: Debe = Haber.
10. Estado de resultados: Ventas - Costo de ventas - Gastos.
11. IVA neto: IVA por pagar - IVA crédito fiscal.
12. Abrir datos de una fase anterior y comprobar que la migración agrega los campos nuevos sin perder datos.
